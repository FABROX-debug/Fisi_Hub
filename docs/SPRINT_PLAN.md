# Plan de Sprints - FISIHUB MVP

## Sprint actual

### Sprint 1 - Sistema de diseno y layout base

**Estado:** En curso

**Objetivo:** establecer la base visual del MVP mediante tokens de diseno,
componentes reutilizables, layout responsive, rutas iniciales y un dashboard
temporal sin integracion con backend.

**Entregables:**

- React Router v6 y navegacion base.
- Sidebar, topbar y area principal responsive.
- Componentes Button, Input, Card, Badge, ProgressBar y Toast.
- Paginas placeholder del MVP.
- Dashboard visual con datos temporales.
- Backend de salud sin cambios funcionales.

## Sprints completados

### Sprint 0 - Estructura inicial

**Estado:** Completado

- Estructura `frontend`, `backend` y `docs`.
- React, Vite y TailwindCSS.
- Spring Boot MVC y configuracion PostgreSQL.
- Endpoint `GET /api/health`.

## Planificacion futura
